El objetivo de esta actividad es que los estudiantes practiquen operaciones con vectores, como la búsqueda de valores, la determinación de máximos y mínimos, la identificación de múltiplos, y la manipulación de vectores para crear nuevos conjuntos de datos basados en condiciones específicas.
